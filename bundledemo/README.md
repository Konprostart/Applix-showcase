# Bundle Explorer

Lists and reads the files bundled with the app. Shows the storage and SQLite bridges plus bundled resources.

**Bridges used:** sqlite, storage

**Resources:** 1 file(s)

## How to use

Open Applix -> Create -> Showcase -> pick this app -> Build. It installs as a normal Android app with its own icon.

## Source

`app.html` in this folder - a single self-contained HTML file.
